# Premier League Analysis (2000–2025)

Analysis of 25 seasons of English Premier League match data using SQL and Python.

## Dataset
- Source: Kaggle — EPL Match Data 2000–2025
- Size: 9,380 matches, 22 columns
- Coverage: Seasons 2000/01 to 2024/25

## Tools Used
- PostgreSQL — data storage and SQL analysis
- Python (pandas, matplotlib) — data analysis and visualization
- Jupyter Notebook — interactive analysis
- Git/GitHub — version control

## Key Findings
- Most wins: Manchester United (552 wins over 25 seasons)
- Most goals: Arsenal (all-time top scorer)
- Home advantage: Home team wins 45.8% of matches vs 24.7% for away teams
- Guardiola effect: Man City went from ~15 wins/season to 28-32 after 2016/17
- Most yellow cards: Chelsea
- Most red cards: Arsenal
